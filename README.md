# Hospital Management System

Java console-based Hospital Management System for our final project.
It manages patients, doctors, appointments, medical records, rooms, admissions and bills
with separate menus for Admins, Doctors and Patients.

**Group 2 - C2A:** Dapito, Lanto, Mellomida, Zapata

## Run

```
javac -d out $(find src -name "*.java")
java -cp out Main
```
